# MOAT — Que pourrait posséder VideoOVNI que YT / TikTok / Wikipedia ne font pas mieux ?

## Candidats
| Actif | VideoOVNI aujourd’hui | Déjà mieux ailleurs ? |
|---|---|---|
| Vidéo originale exclusive | Non observé (renvoi TikTok) | YouTube créateurs |
| Base structurée date/lieu/source/statut GEIPAN | Non (pas une DB FR) | GEIPAN + CarteOvni |
| Chaîne de garde / fichier original | Ambition éditoriale | Rare ; valeur réelle si **pipeline** — inexistant à l’échelle |
| Explication / niveau de preuve (sans score magique) | Articles méthodologiques | Possible, mais **copieable** ; sans audience = inutilisé |
| Carte / timeline | Timeline éditoriale possible | CarteOvni (carte), Wiki (timeline narrative) |
| Traduction FR docs US | Oui, corpus | Avantage **temporaire**, pas un fossé |
| Communauté / témoignages | Non visible | Forums, LDLN, Reddit |

## Réponse nette
**Aujourd’hui : pas de moat.**

Le seul fossé envisageable serait une **base d’analyses vidéo avec fichiers originaux + métadonnées + verdict sourcé**, impossible à remplacer par un Short. Ça exige ops lourdes, crédibilité, et distribution. Ce n’est pas ce que le site monétise ou indexe aujourd’hui.

Wikipedia gagne la définition. YouTube gagne la vidéo. GEIPAN gagne l’officiel FR. CarteOvni gagne la carte. Il ne reste que des miettes long-tail **sans défense**.
