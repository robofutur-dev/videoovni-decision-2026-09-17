# MONETISATION — Test objectif

| Modèle | Réaliste ? | Pourquoi |
|---|---|---|
| Display / AdSense | Non à ce stade | ~0 trafic Google ; pas de `ca-pub` home ; même à 10k sessions/mois thématique « OVNI » = RPM médiocre + risque brand safety |
| YouTube Partner | Possible *si* chaîne | Le site n’est pas le véhicule ; cannibalisation naturelle vers YT |
| Affiliation jumelles / caméras / astro | Faible | Volumes d’achat bas ; intention « croire/voir » ≠ « acheter une ASIAIR » |
| Newsletter sponsorisée | Théorique | Zéro liste connue ; sponsor UAP rare et méfiant hors US |
| Sponsoring marque | Non | Pas d’audience prouvable |
| Data / licence | Non | GEIPAN open data ; pas d’actif propriétaire |
| Membership / paywall | Non | Contenu non exclusif face au gratuit officiel |

## Conclusion
**Aucune monétisation réaliste sur l’actif web actuel.** Forcer un business model serait de la fiction. Le TikTok `@video.ovni` est le seul embryon de distribution monétisable — et encore, non prouvé ici (pas d’accès stats créateur).
