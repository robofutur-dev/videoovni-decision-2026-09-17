# POSITIONING — Tests A–E

## A — Agrégateur vidéos OVNI
- **Fit actuel :** partiel (hub TikTok + promesse « vidéos »).
- **Problème :** YouTube/TikTok **sont** l’agrégateur. Un site qui pointe vers TikTok est un détour.
- **Verdict :** à abandonner comme thèse web.

## B — Média UAP factuel
- **Fit actuel :** le plus proche du site (dossiers, méthode, sources institutionnelles).
- **Problème :** sans marque, sans email, sans Discover, sans YT — un média factuel meurt. Concurrent implicite : journalistes + créateurs crédibles.
- **Verdict :** viable **seulement** avec canal distribution ≠ SEO seul. En l’état : non.

## C — Base française d’observations sourcées
- **Fit actuel :** faible (le site est US-heavy + historique mondial).
- **Problème :** GEIPAN = source ; CarteOvni = UX carte déjà là.
- **Verdict :** **non** — redondant.

## D — Fact-check / analyse vidéos
- **Fit actuel :** ambition présente (métadonnées, FLIR, guides).
- **Problème :** le format gagnant est la **démonstration vidéo** (Shorts/TikTok/YT), pas l’article 3 000 mots introuvable.
- **Verdict :** meilleur *métier* possible, mauvais *véhicule* actuel (site SEO).

## E — Autre
- Newsletter « briefing UAP FR » hebdo : possible mais micro-audience.
- Data/API observations : déjà open data GEIPAN.
- Affiliation matériel astro : annexe, pas un cœur de projet.

## Tranche
**Aucune position web ne justifie d’investir encore du capital dans VideoOVNI.fr tel quel.**

Si une vie secondaire existait un jour, ce serait **D exécuté en natif vidéo** (pas un rebuild SEO). Ce n’est **pas** un INVESTIR sur le site ; ce serait une **nouvelle thèse** — hors scope « mérite encore du temps et du capital » sur l’actif actuel → **GELER** l’actif web.
