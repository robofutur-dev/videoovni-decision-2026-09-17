# SERP — Qui possède réellement les résultats (FR)

Audit SERP via WebSearch (2026-09-17). Échantillon non exhaustif mais directionnellement stable.

## Cartographie des gagnants
| Acteur | Force | Faiblesse |
|---|---|---|
| **YouTube / Shorts** | Intention « vidéo », watch-time, créateurs (ex. enquêtes type Grand JD) | Peu de profondeur documentaire structurée |
| **GEIPAN / CNES** | Autorité d’État, base de cas, procédure de signalement | UX datée, pas un média vidéo |
| **Wikipedia** | Définitions, entités, liens entrants massifs | Pas de flux actu ni analyse vidéo |
| **Médias locaux / nationaux** (actu.fr, etc.) | Confiance + Discover + SEO local sur faits divers | Couverture épisodique |
| **CarteOvni.fr** | Carte interactive, 3 195+ cas GEIPAN, météores GMN, open data | Moins « dossier UAP US » |
| **Reddit / forums / LDLN** | Discussion, témoins, niches | SEO limité, bruit |
| **VideoOVNI.fr** | Corpus long-form sourcé (si crawl OK) | **Absent des SERP observés**, 0 notoriété, domaine 05/2026 |

## Conclusion SERP
Les SERP ne sont pas « vides » : elles sont **occupées par des acteurs avec distribution native**. VideoOVNI n’a **aucun siège** aujourd’hui. Gagner un siège SEO organique demanderait des années d’autorité **ou** un pivot hors SEO.
