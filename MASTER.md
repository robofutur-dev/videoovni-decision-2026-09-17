# MASTER — Décision d’investissement VideoOVNI.fr
**Date :** 2026-09-17  
**Rôle :** Investment Analyst / Growth Lead  
**Baseline :** ~5 impressions Google / 7 jours, 0 clic  
**Préférence owner :** fermer un projet faible plutôt que le sauver par principe

---

## DÉCISION : GELER

### POURQUOI
VideoOVNI.fr a un **corpus éditorial déjà dense** et une **DA crédible**, mais :
1. **Zéro découverte** (impressions ~nulles, mentions web absentes, domaine créé le **2026-05-02**).
2. L’intention « vidéo OVNI » est **structurellement YouTube/TikTok**, pas un site HTML.
3. Les niches FR « officielles » sont **prises** (GEIPAN, CarteOvni).
4. Risque crawl **LWS Anubis** (challenge y compris face à un UA Googlebot en audit).
5. Multilingue ×5 avant traction FR = **gaspillage**.
6. **Pas de moat**, **pas de monétisation** réaliste sur l’actif actuel.

Investir plus de temps/capital dans le site, c’est payer un ticket SEO que le marché a déjà attribué à d’autres. Pivoter « un peu » sans tuer le véhicule web prolongerait le coût. **Geler** est la décision alignée données + préférence anti-complaisance.

### PROBLÈME #1
**Découverte / autorité / distribution** (pas le volume de contenu), avec **aggravation crawl/WAF** et **mauvais fit canal**.

### DEMANDE
Réelle mais **limitée et episodique** en France. Proxy : ~98 vues/j sur l’article Wikipedia FR OVNI ; GEIPAN ~1–1,8k signalements/an. ≠ product-market fit pour un média web neuf.

### POSITIONNEMENT
Aucun des A–E ne justifie de continuer le site. Le moins mauvais métier (fact-check vidéo) exige un **autre véhicule** (vidéo native), donc une autre thèse — pas un INVESTIR ici.

### MOAT
**Aucun** aujourd’hui.

### CANAL #1
**Vidéo sociale / YouTube** (nature du sujet) — pas Google Search pour cet actif.

### MONÉTISATION
**Aucune réaliste** sur le site à trafic nul.

### COÛT / COMPLEXITÉ
Continuer : coût temps éditorial élevé, ROI SEO 12–24 mois **non garantis**, ops WAF/multilingue.  
Geler : coût ≈ renouvellement domaine (~faible) + backup.

### PLAN 90 J
Gel production, backup, audit GSC/Anubis, parking domaine, revue TikTok comme projet **séparé** seulement si traction mesurée. Détail : `90-DAYS.md`.

### P0 OPENCODE
Stop contenu + GSC + backup + inventaire comptes. Détail : `OPENCODE-EXECUTION.md`.
